## 📖 About

**Szip** is a powerful, easy-to-use compression and archiving tool that brings together all the features you need in one place. Whether you need to compress files, extract archives, or manage compressed data, Szip has you covered.

---

## ✨ Features

- 📦 **Compress** files and folders quickly and efficiently
- 📂 **Extract** archives with ease
- 🔒 **Secure** — password-protect your archives
- ⚡ **Fast** — optimised algorithms for speed and compression ratio
- 🖥️ **Cross-platform** — works on Windows, macOS and Linux
- 🧩 **Multiple formats** — supports ZIP, TAR, GZ, and more

